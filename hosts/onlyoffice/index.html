Connect to your TeX installation

LavaTeX renders with the TeX already on your computer (TeX Live, MiKTeX, MacTeX or Tectonic) through a small helper program. Start it once, then paste its access token below.

  1. Install LavaTeX and run lavatex serve (keep it running, or add it to your startup programs).
  2. Run lavatex token and paste the token here.
Display math by default. Use aligned or gathered with \\ for several lines. Ctrl+Enter inserts.
