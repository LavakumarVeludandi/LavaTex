One-time setup needed

LavaTeX renders equations with the TeX installed on this computer (TeX Live, MiKTeX or MacTeX), just like IguanaTeX. ONLYOFFICE plugins cannot start programs themselves, so a small LavaTeX helper does the rendering. It is set up once and then starts by itself.

  1. Install a TeX distribution if you do not have one yet.
  2. Download LavaTeX for your system from github.com/LavakumarVeludandi/LavaTex/releases.
  3. In a terminal, run lavatex setup onlyoffice.
